# Average Sensor Readings

## Project Purpose
This project uses a small Python program to analyse sensor readings. It prints the count, minimum, maximum, and average of the readings.

## Readings Used
[22, 24, 26, 28, 30]

## Expected Output
- Count: 5
- Minimum: 22
- Maximum: 30
- Average: 26.0

## How to Run
1. Open Google Colab at colab.research.google.com.
2. Click File → Upload notebook and select the notebook file from this repository (or create a new notebook and paste the code).
3. Click Run on the code cell.
4. The output appears below the code cell.
